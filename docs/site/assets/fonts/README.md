# Documentation fonts

These Latin WOFF2 subsets are shared with the perps-core documentation in `docs/assets/fonts/`: Manrope for body text, Inter for headings, and JetBrains Mono for code. They are served locally so the guide also works without a network connection.

The protocol guide uses Manrope for body text and secondary headings, Cinzel for chapter titles, and JetBrains Mono for code and numeric labels. `cinzel.woff2` is the WOFF2 conversion of the bundled variable Cinzel font, covering weights 400–900. Its license is in [`../cinzel.LICENSE.txt`](../cinzel.LICENSE.txt).

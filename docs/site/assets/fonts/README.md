# Documentation fonts

These Latin WOFF2 subsets are shared with the perps-core documentation in `docs/assets/fonts/`: Manrope for body text, Inter for headings, and JetBrains Mono for code. They are served locally so the guide also works without a network connection.

The protocol guide matches `vaults-ui`: Manrope for body text and secondary headings, Belleza for branding and chapter titles, and JetBrains Mono for code and numeric labels. `belleza/belleza-latin-400.woff2` is the same regular-weight font bundled in `vaults-ui/public/fonts/belleza/`. Its license is in [`belleza/OFL.txt`](belleza/OFL.txt).
